# tg-antispam-ru

Антиспам-бот для русскоязычных Telegram-чатов. Работает на правилах, без нейросетей и платных API: каждое сообщение получает баллы за признаки спама, и при превышении порога бот удаляет сообщение, а при высоком счёте банит автора.

Бот вырос в реальном чате курьеров и водителей и заточен под типичный русскоязычный спам: «подработка 5000р за выход», «пиши в лс», закладчики, крипто-обмен, займы, интим-боты, «работа за границей с жильём».

## Что умеет

- **130+ правил** с баллами: суммы в рублях, увод в личку, «за выход», наркотический сленг, крипта, займы, вакансии-приманки и т.д.
- **Обход обфускации:** латиница вместо кириллицы (`вοдитeль`), невидимые символы внутри слов, буквы через точку (`К.Л.А.D.М.Е.Н`), разрядка (`Р А Б О Т А`), `п одработка`.
- **Premium-«шрифты»:** текст, набранный кастомными эмодзи-буквами, ловится по их количеству.
- **Пересылки от ботов** с кнопками-ссылками; текст кнопок тоже проверяется.
- **Репутация:** у участников с историей обычных сообщений порог удаления выше, новички проверяются строже.
- **Отчёты** об удалениях в личку админу или в лог-чат, с кнопками «Вернуть в чат» и «Разбанить».
- **Повторная проверка** отредактированных сообщений (спамеры пишут безобидное и потом правят).
- **Ручная модерация:**
  - `/spam` — админ ответом на сообщение: удалить, забанить, удалить остальные недавние сообщения автора;
  - `/report` — любой участник: жалоба уходит админу с кнопками «Удалить + бан» / «Не спам»;
  - `/delete` — «ночные сторожа» (доверенные участники): удалить без бана, автор заглушён до решения админа.

## Установка

Нужен Node.js 18+.

```bash
git clone https://github.com/<you>/tg-antispam-ru.git
cd tg-antispam-ru
npm install
cp config.example.js config.js
```

Создайте `.env` рядом с `config.js`:

```
TOKEN_DELETE=123456:ABC...        # токен от @BotFather
LOG_CHAT_ID=123456789             # кому слать отчёты; несколько — через запятую
```

`LOG_CHAT_ID` — ваш id (узнать: @userinfobot) или id группы/канала для логов (начинается с `-100`). Чтобы бот мог писать вам в личку, сначала нажмите у него **Start**.

Запуск:

```bash
npm start
```

Для постоянной работы удобно использовать [pm2](https://pm2.keymetrics.io/): `pm2 start delete.js --name antispam`.

### Права бота в группе

Добавьте бота **администратором** с правами:
- удалять сообщения;
- блокировать пользователей (бан и временное ограничение для `/delete`).

Будучи админом, бот видит все сообщения независимо от privacy mode.

## Настройка (`config.js`)

| Параметр | Что это |
|---|---|
| `spamScoreThreshold` | порог удаления (по умолчанию 4) |
| `banScoreThreshold` | порог бана (по умолчанию 7) |
| `wordsToRemove` | слова/фрагменты, +3 балла каждое (ссылки, «казино», …) |
| `strongSpamPhrases` | фразы, +5 баллов — новичок удаляется сразу |
| `wordsToKeep` | доверенные сайты (YouTube, Google Docs…): ссылка на них не штрафуется, но остальной текст проверяется — «работа в YouTube, 5000р, пиши в лс» всё равно удалится |
| `trustedLinks` | ваши каналы, сайты и доверенные контакты: сообщение с **настоящей ссылкой или @упоминанием** на них не проверяется. Просто слово без ссылки не считается |
| `exemptUserIds` | id пользователей, которых бот не проверяет (админы, доверенные) |

Репутация: после 5 обычных сообщений порог +2, после 25 — +4. Хранится в `userStats.json`.

## Команды

| Команда | Кто | Где | Что делает |
|---|---|---|---|
| `/spam` | админы, `exemptUserIds` | ответом на сообщение в группе | удалить + бан + удалить недавние сообщения автора |
| `/report` | любой участник | ответом на сообщение | жалоба админу с кнопками |
| `/delete` | ночные сторожа | ответом на сообщение | удалить, заглушить автора до решения (макс. 24ч) |
| `/watch add <id>` | получатель отчётов | в личке бота | назначить сторожа |
| `/watch remove <id>` | получатель отчётов | в личке бота | снять сторожа |
| `/watch list` | получатель отчётов | в личке бота | сторожа и их точность |

Защита от злоупотреблений `/delete`: нельзя удалить сообщение админа, другого сторожа или участника с 25+ сообщениями (команда превращается в жалобу); лимит 10 удалений в час; после 3 отменённых админом удалений сторож отключается автоматически.

## Особенности правил

Правила подобраны под русскоязычный чат **в Польше**: суммы в рублях — признак спама, злотые — нет; «водитель», «курьер», «рейс» — обычные слова. Для чата в другой стране или тематике часть правил стоит пересмотреть (см. `spamScore()` в `messageHandler.js` — каждое правило прокомментировано).

## Тесты

```bash
npm test
```

`test.js` — ~300 реальных сообщений: спам, который должен удаляться, и обычные фразы, которые трогать нельзя. Добавляйте туда каждый новый пропуск или ложное срабатывание перед правкой правил.

## Ограничения

- Текст на картинках не распознаётся.
- Удалённые сообщения для кнопки «Вернуть» и недавние сообщения для чистки после бана хранятся в памяти — после перезапуска недоступны.
- Telegram позволяет ботам удалять только сообщения младше 48 часов.
